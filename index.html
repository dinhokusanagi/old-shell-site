Desktop Linux

Old Shell

Um ambiente de desktop Linux em desenvolvimento, criado para reunir controles do sistema, notificações e integrações em uma experiência coesa e personalizável.

Sobre o projeto

Old Shell é um projeto independente para Linux. Algumas funcionalidades podem oferecer integração com serviços externos, como os serviços Google, mediante autorização explícita do usuário.
